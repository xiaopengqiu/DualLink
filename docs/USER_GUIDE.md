# 使用指南

## 第一次连接

1. 管理员部署网站并创建账号。
2. Windows 安装「双端互联」或打开免安装版。
3. 输入云服务地址（支持 http://公网IP:端口 或 HTTPS），开始配对。
4. iPad 打开同一网站登录，在「设备」输入客户端显示的配对码，或扫描二维码后登录并批准。
5. 客户端显示已连接后，使用界面显示的快捷键截图。

配对码短期有效，过期可以重新生成。设备凭据由 Windows 系统加密保存在当前用户目录；卸载/更换 Windows 用户后可能需要重新配对。网站撤销设备会使旧凭据失效。

## 截图和回答

客户端可选择显示器，设置全屏/框选快捷键。框选时拖动选择区域，Escape 取消。开机启动由你在设置里选择开启。

截图只保存在本机「本题待回答截图」，可以连续截图、预览、移除或清空。确认题目截全后按 Ctrl+Alt+Enter（可修改）或点击「回答这道题」，将当前所有截图作为同一道题提交，只生成一份整体回答。触发后新截图进入下一题。网页上传也须明确点击回答，支持一次选择多张。缓存、排队及升级说明见[多图整题回答](SCREENSHOT_BATCHES.md)。

局域网优先会尝试 WebRTC 直传到当前打开的 iPad 网页；只有成功上传云端后才确认接收。iPad 关闭、锁屏、权限未允许或直连失败时，PC 自动走云端。图片仍会交给云端模型，局域网直连并不表示完全离线。

## Prompt

在「Prompt」维护多套回答风格并选择默认项，例如：

```text
用中文回答。先给出可直接使用的结论，再补充关键依据。
代码题给出思路、代码、时间和空间复杂度。
涉及个人经历时依据知识库，不编造未提供的事实。
截图不清楚时指出需要补充的部分。
```

任务提交时保存 Prompt 快照，之后修改 Prompt 不会改变已经提交的任务。

## 知识库

支持 TXT、Markdown、PDF 和 DOCX。每个文件最大 10 MiB；扫描版 PDF 可能没有可提取文字，应先 OCR 或转成文本再上传。当前实现会按相关词和文本预算选择资料片段，不会无上限塞入整个目录。

资料只对当前账号可见。建议分成「个人简介」「项目经历」「常见问题」「回答规范」等清晰文件。长篇资料可以按主题拆分，以改善检索。就绪资料超过上下文预算时，服务会先调用模型从截图提取检索问题，再按关键词选片段并正式回答；这会增加一次模型调用。界面会显示检索阶段，提取失败会提示降级使用有限片段。删除知识文件不会抹去历史答案中已经引用的片段。

## 常见问题

- **快捷键无效**：检查是否被其他软件占用，改用别的组合，并在托盘打开客户端查看连接状态。
- **模型认证失败**：由管理员检查服务器服务用户的 CLI 登录/API key，而不是修改 iPad 浏览器。
- **切后台后没有实时更新**：重新打开页面会从服务器恢复持久化结果；不要依靠 iPad 网页后台持续上传。
- **局域网连不上**：确认两端在同一网络、未启用设备隔离，允许浏览器所需权限；云端回退仍可工作。
- **代码字太小**：优先框选问题区域，使用清晰原图，避免整张超大桌面缩小后再传。
- **忘记网站密码**：由管理员在账号管理中重置。管理员可在服务器运行账号管理 CLI，见部署指南。

## 管理账号

管理员可以创建用户、设置每日任务限额、禁用用户和重置密码。禁用会撤销活跃登录和设备访问。截图、Prompt、知识库和任务始终按账号隔离；网站账号额度与模型供应商实际计费分别管理。

## 实时语音与全场记录

1.1 新增客户端「面试录音」与网站「面试会话」。管理员配置百炼语音密钥后，PC 可同时采集系统会议声音和所选麦克风，iPad 查看双方转写、AI 建议与历史。自动回答使用定稿发言，也支持手动选段或输入校正问题。本人说过的话与 AI 建议分别保存，后续回答可以参考前面的实际对话。

暂停、继续、结束、断线恢复、JSON / Markdown 导出及延迟说明见 [实时语音指南](VOICE_GUIDE.md)。当前为系统混音采集，其他应用声音也可能进入远端轨；戴耳机无需外放。


## 1.2双模式与回答快捷键

按账号保存音频直答/转写后回答默认值，PC开始前也可选择。本场切换配置先暂停。默认持续采集、Ctrl+Alt+Enter触发回答，快捷键可修改；录音尾音会在触发前同步。音频直答后台转写可选，关闭后无逐字文字记录。详见[双模式指南](DUAL_MODES_GUIDE.md)。

# 客户端一键升级实施计划

**目标：** Windows 安装版与便携版可在偏好设置检查、下载、校验并安装新版，保留配对、偏好与本地数据。

**方案：** 固定从 xiaopengqiu/DualLink 的 GitHub Releases 稳定版本获取对应架构/包类型及 SHA256SUMS。主进程执行网络、文件校验及安装，渲染进程只能调用无参数操作。选择此方案以沿用现有发布资产并兼容便携版；单独采用 NSIS 自动更新会让便携版仍需手工替换。下载与安装由用户显式触发，启动只检查，不自动下载或退出。

**步骤：**
1. updater.cjs 与测试：先测试版本判断、固定来源、下载进度/上限/校验、错误恢复与任务阻塞，再实现控制器。
2. update-install.cjs、update-portable.ps1 与测试：安装版启动 NSIS；便携版通过隐藏帮助进程等待退出、替换、备份、失败回滚。全程使用绝对路径、参数数组与 LiteralPath，不使用拼接的命令字符串。
3. 主进程、preload 与更新界面：增加检查、下载、安装 IPC；安装前检查录音/截图/上传/回补状态并阻止新任务。显示当前/最新版本、进度、错误、阻塞原因。开发模式说明不可安装。
4. 发布：1.4.0 新增启动检查开关，生成所有安装包/源码/网页与 SHA256SUMS；发布文档说明1.3.0须手动安装本次版本一次，此后使用客户端升级。
5. 验证：控制器和安装帮助进程单元测试、真实 Electron IPC/界面流程、临时文件目录便携替换与回滚演练、旧截图/语音回归、打包文件对比。测试不替换当前真实客户端安装。

**边界：** 此功能更新 PC 客户端，不自动部署云端；GitHub不可达时显示可重试错误。当前发布包未配置 Windows 代码签名，使用固定 HTTPS 来源及 SHA-256 完整性检查，不声称具备独立签名认证。

# 1.2 双模式与快捷键回答

音频直答与转写后回答均可配置，默认持续记录、手动触发。PC 默认回答快捷键为 **Ctrl+Alt+Enter**，在「偏好设置」中可修改；与截图快捷键冲突时会提示。Windows 客户端、云端及网页均需更新到1.2.0。

## 选择与使用

网站「面试会话」的默认配置可按账号保存：回答模式、文字模型、音频模型、后台转写和问题回看时长。PC 新建会话时读取这些默认值，也可以在开始前为本场单独选择。已经开始录音后，先暂停再切换回答模式、音频模型或后台转写设置，再继续录音。已有会话与历史答案的配置快照独立。

| 模式 | 生成回答的输入 | 模型 |
|---|---|---|
| 转写后回答 | 当前远端问题文字＋本人实际发言与历史摘录＋Prompt/知识库 | Codex、Claude、百炼文本 API |
| 音频直答 | 当前远端问题原始音频＋分轨标记的近期音频＋已存在的文字历史与Prompt/知识库 | 百炼 Qwen-Omni 实时模型 |

开始录音后不会因一段声音结束而自动生成建议。按快捷键，或点击 PC/网页的「回答当前问题」，才提交本次回答。转写模式保留显式选择的自动回答兼容选项，音频直答始终手动。

触发前 PC 刷新尚未发送的尾音，并等待已发送帧的云端确认；这个过程不会停止采音。未连接或仍有待同步音频时会提示等待，不会用旧的云端输入假装回答当前题。新的触发会取消未完成的旧回答，短时间连按去重；远端没有新有效声音时重答上一个问题。本人声音仅作为历史，不当作面试官提问。

## 云端启用音频直答

当前直接音频接口接入 Qwen-Omni，复用百炼 Key、业务空间和地域：

```ini
DASHSCOPE_API_KEY=你的服务端密钥
DASHSCOPE_WORKSPACE_ID=对应业务空间ID
ASR_REGION=cn-beijing
OMNI_MODEL=qwen3.8-omni-flash-realtime
INTERVIEW_DEFAULT_MODE=transcript
INTERVIEW_AUDIO_WINDOW_SECONDS=120
```

需要独立认证或地域时可覆盖：

```ini
# OMNI_API_KEY=音频模型密钥
# OMNI_WORKSPACE_ID=音频模型业务空间ID
# OMNI_REGION=cn-beijing
# OMNI_WS_URL=wss://业务空间ID.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime
# OMNI_MODELS=qwen3.8-omni-flash-realtime,qwen3.5-omni-flash-realtime
```

`OMNI_MODELS` 是服务器允许选择的模型列表，默认仅有 OMNI_MODEL。所用 Key 必须具有所选模型的权限与额度。音频直答使用新的模型 API 调用，不能由已登录的 Codex/Claude 直接替代；截图和文字问答仍可以使用原 CLI。Key 不进入网页或客户端。

升级时安装脚本保留旧环境文件，需手动添加新的模型项。编辑 `/etc/dual-link.env` 后执行：

```bash
sudo systemctl restart dual-link
sudo journalctl -u dual-link -n 100 --no-pager
```

Qwen接口使用手动音频提交、关闭前置转写及自动回复、只输出文字。每题新建模型会话，明确标记本人/远端音频来源，只在输入全部提交后请求回答，避免把以前生成的 AI 建议作为现场已说过的话。模型与协议说明见[百炼官方文档](https://help.aliyun.com/zh/model-studio/realtime)。

## 后台转写与整场记录

音频直答的后台转写默认开启，但回答不等待其完成。它用于字幕、历史检索及后续上下文；转写服务暂时不可用时应提示降级，原始音频和音频直答仍可工作。转写后回答模式则必须先有可用 ASR。音频直答、转写两个服务分别检查可用配置，不会悄悄把音频直答改成文字问答。

关闭后台转写时，会保存实际音频和问题音频范围、回答、模式及上下文记录，但不会伪造逐字转写。网页可访问保留的双方录音，JSON/Markdown 导出包含问答及相关元数据。

全部历史归档不等于全部历史都无限量送入模型。每次音频问题按配置回看最近15–180秒；过长问题被截断时会显示提示，近期音频作为额外背景。较早的已转写发言可通过现有历史检索选入；关闭后台转写时，较早、超出本次音频上下文的内容可能不在本次输入中。需要完整文字历史和更好的早期事实检索时，请保持后台转写开启。AI建议与本人实际发言始终分开。

正在进行或暂停的会话需要临时保存 PCM 供快捷键回答，录音容量上限仍适用。`AUDIO_RETENTION_DAYS=0` 在1.2表示结束且相关音频回答处理完成后删除工作音频；文字记录独立保留。原始音频过期/删除后，旧音频问题可能无法重新生成，应使用已有答案或手工整理文字问题。

## 验收

1. 新建音频直答会话，关闭后台转写，播放一句测试问题；未按键时确认没有模型回答。
2. 按快捷键确认 iPad 收到文字建议；静默后再次触发，确认重答同一题。
3. 暂停并切换转写后回答，继续录音；确认字幕先保存，按键后才生成建议。
4. 开启音频直答后台转写，确认回答不依赖前置 ASR 完成，转写用于后续历史。
5. 检查本人实际发言进入后续上下文、AI建议未冒充本人发言；结束并导出。

客户端到你云端仍支持 HTTP+公网IP+端口。云端到供应商使用其 WSS/HTTPS 接口。自动化验证使用本地模型协议服务；真实模型质量、音频成本和首字延迟需在你的密钥、ECS及会议设备上验收，不承诺固定延迟。

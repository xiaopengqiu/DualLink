## 验证边界

- 没有服务器 SSH 信息，因此没有替用户登录或更改阿里云服务器，也没有在真实 Linux 上执行 systemd / Docker 部署。部署文件已做语法与路径/权限审查；本机 Docker Engine 未能就绪，未将其算作运行验证通过。
- 真实 Claude 认证与模型服务尚未调用；需要在云端服务账号下验收现有安装、凭据、模型名称和网络。
- 没有可用百炼密钥，未调用真实语音识别或百炼文本模型，无法报告真实识别准确率、端到端语音延迟或云端吞吐。物理麦克风、耳机、会议软件、蓝牙模式切换仍需按语音指南预检；现有合成源和协议测试不能代替这些验收。
- 平板布局和 WebRTC 已在本机真实浏览器验证；没有实体 iPad，不能代替 iPad Safari、Wi-Fi 路由器设备隔离、系统本地网络权限的真机验收。
- 桌面自动化验证了实际截图按钮和框选；测试模式避免改动系统自动启动及全局快捷键。生产模式使用 Electron 全局快捷键 API，并提示快捷键占用，需要在实际使用环境确认键位。
- 安装包未签名；已验证打包 EXE/ASAR 的实际运行，没有向当前用户的系统目录安装 NSIS 产品。
